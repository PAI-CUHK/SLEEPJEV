# Changelog

All notable changes to this project will be documented here.

## [0.1.0] - 2026-09-23

### Added

- Public sleepjev package with a reusable overnight SleepCache.
- `src/` layout with a `pyproject.toml` build configuration.
- Runtime SleepQuery options, temporal constraints, event postings, and sparse readout.
- Architecture, installation, development, data, benchmark, and release documentation.
- GitHub Actions test/build workflow.
- Synthetic CLI demo, examples, package tests, documentation, and editable SVG assets.

### Notes

- This is an alpha research release.
- Datasets, credentials, model checkpoints, and generated result archives are not included.
- Clinical deployment and clinical validity are explicitly out of scope.
