# Data and Models

This project publishes code and synthetic examples. Raw PSG recordings, restricted annotations, trained checkpoints, and generated result archives remain external. The public model consumes the `SleepNight` feature contract and provides compact Sleep-EDF/NSRR adapters as optional utilities.

Before sharing a model, document its training dataset, subject-level split, channel selection, epoch length, feature schema, seed, checkpoint hash, calibration scope, and license. A model output is a research estimate over an explicit query option set; it is not a diagnosis, prognosis, treatment recommendation, or patient-risk estimate.
