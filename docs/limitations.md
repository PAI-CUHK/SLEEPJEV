# Limitations

- No clinical validation, prospective study, regulatory review, or deployment claim is included.
- The compact EDF feature adapter may not match a laboratory's validated PSG preprocessing.
- Dataset channel names, scoring conventions, event definitions, and coverage differ.
- Preliminary results need protocol recovery, independent reruns, subject-level splits, multiple seeds, and uncertainty intervals.
- Runtime option flexibility does not by itself establish semantic generalization.
- Query-reuse speedups depend on workload size, cache construction, device, and timing policy.
- The current public package does not ship pretrained weights or a fully automated data-download pipeline.
