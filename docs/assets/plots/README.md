# Release plots

These figures are generated by [`scripts/plot_results.R`](../../../scripts/plot_results.R)
with `ggplot2` and `scales`.

- `high_q_hit5`: hit@5 across the high-query regime.
- `serving_speedup`: warm serving speedup relative to Independent DL.
- `qa_qps`: quality-adjusted query throughput using the conservative QAI metric.
- `high_q_summary.csv`: source values and derived columns used by the plots.

The numbers are final two-seed averages supplied for this release summary. Warm
serving excludes EDF I/O and overnight cache construction. PNG files are used on
the README homepage; SVG and PDF files are retained as editable publication assets.
